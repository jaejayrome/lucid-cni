# Lucid CNI

This repository and personal project of mine lies in my fondness of understanding things at a lower abstraction level. I wanted to understand how CNIs (Container Network Interfaces) are being built and the different ways that one can implement them.

There are many enterprise and production-grade CNIs in the market right now, namely: Cilium, Calico and Flannel.
